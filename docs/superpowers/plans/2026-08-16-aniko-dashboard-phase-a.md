# AniKo Dashboard Phase A (Shell & Routing) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the AniKo frontend and the `DashboardShell` — sidebar, header, responsive grid, routing and locale — so that Phases B–I have somewhere to render.

**Architecture:** A Vite + React 19 + TypeScript app under `frontend/`, organised feature-sliced. `DashboardShell` owns chrome and layout only; it never knows a panel's name. Every visible string goes through i18n from the first commit, and a parity test fails the build if the English and Filipino catalogues drift apart. Session data comes from a mock module behind a hook, so Phase I can swap it for real auth without touching a component.

**Tech Stack:** Vite 7, React 19, TypeScript 5 (strict, project references), Tailwind CSS v4, shadcn/ui, react-router v7, react-i18next, Vitest + React Testing Library + jsdom, lucide-react.

**Spec:** `plan/dashboard plan/aniko-dashboard.md` (Phase A), with design rules in `plan/frontend plan/ui-ux.md`.

## Global Constraints

- The repo is a clean slate — `master` has one commit containing only `.gitignore`. Nothing described here already exists.
- All app code lives under `frontend/`. All commands in this plan run from `frontend/` unless stated otherwise.
- `tsconfig.app.json` and `tsconfig.node.json` **must both** set `"composite": true` — the root `tsconfig.json` references them as a project-references solution and the build fails without it. This bit the previous AniKo build; do not skip it.
- TypeScript `strict: true`. No `any` in committed code.
- **No raw hex values in components.** Colour comes from CSS custom properties defined in `src/index.css`. Phase B replaces the placeholder values; Phase A only establishes the indirection.
- **Every visible string is an i18n key.** English (`en`) and Filipino (`fil`) catalogues stay in parity, enforced by a test.
- Every interactive element has an accessible name. Touch targets are at least 44×44px.
- shadcn/ui primitives are generated by the CLI into `src/components/ui/` and are not hand-edited.
- Commit after every task. Conventional commit prefixes (`chore:`, `feat:`, `test:`).

export type UserRole = 'buyer' | 'farmer'

export interface SessionUser {
  id: string
  name: string
  role: UserRole
  verified: boolean
  avatarUrl: string | null
}

export interface Session {
  user: SessionUser | null
  isLoading: boolean
}

const MOCK_USER: SessionUser = {
  id: 'usr_juan',
  name: 'Juan Martinez',
  role: 'buyer',
  verified: true,
  avatarUrl: null,
}

/**
 * Phase A returns a fixture synchronously. Phase I replaces the body with a
 * real fetch — the return shape must not change, because every consumer is
 * already written against `{ user, isLoading }`.
 */
export function useSession(): Session {
  return { user: MOCK_USER, isLoading: false }
}
```

import { NavLink } from 'react-router-dom'
import { useTranslation } from 'react-i18next'
import { BadgeCheck, HelpCircle } from 'lucide-react'
import { NAV_ITEMS } from '@/app/nav'
import { useSession } from '@/lib/session'
import { cn } from '@/lib/utils'

export function Sidebar() {
  const { t } = useTranslation()
  const { user } = useSession()

  return (
    <aside className="flex h-full w-[220px] flex-col bg-surface px-4 py-6">
      <div className="px-2">
        <img
          src="/brand/aniko-logo.png"
          alt={t('app.name')}
          className="h-8 w-auto"
        />
        <p className="mt-1 text-xs text-muted-fg">{t('app.tagline')}</p>
      </div>

      <nav className="mt-8 flex flex-1 flex-col gap-1">
        {NAV_ITEMS.map((item) => (
          <NavLink
            key={item.key}
            to={item.to}
            className={({ isActive }) =>
              cn(
                'flex min-h-11 items-center gap-3 rounded-lg px-3 text-sm font-medium',
                isActive
                  ? 'bg-sidebar-item-active-bg text-sidebar-item-active-fg'
                  : 'text-primary hover:bg-page',
              )
            }
          >
            <item.icon aria-hidden="true" className="size-5 shrink-0" />
            <span className="flex-1">{t(item.labelKey)}</span>
            {item.badge ? (
              <span
                aria-label={t('nav.unread_messages', { count: item.badge })}
                className="rounded-full bg-accent px-2 py-0.5 text-xs font-semibold text-white"
              >
                {item.badge}
              </span>
            ) : null}
          </NavLink>
        ))}
      </nav>

      {user ? (
        <div className="rounded-xl border border-page p-3">
          <p className="text-sm font-semibold text-primary">{user.name}</p>
          <p className="text-xs text-muted-fg">
            {t(user.role === 'buyer' ? 'session.role_buyer' : 'session.role_farmer')}
          </p>
          {user.verified ? (
            <p className="mt-3 flex items-center gap-2 text-xs font-medium text-primary">
              <BadgeCheck aria-hidden="true" className="size-4 text-accent" />
              {t('session.verified_account')}
            </p>
          ) : null}
        </div>
      ) : null}

      <a
        href="/help"
        className="mt-4 flex min-h-11 items-center gap-2 px-3 text-sm text-muted-fg"
      >
        <HelpCircle aria-hidden="true" className="size-4" />
        {t('nav.help')}
      </a>
    </aside>
  )
}
```

import { BrowserRouter, Routes, Route, Navigate } from 'react-router-dom'
import { DashboardShell } from '@/layouts/DashboardShell'
import { Overview } from '@/app/routes/Overview'
import { Placeholder } from '@/app/routes/Placeholder'
import { NAV_ITEMS } from '@/app/nav'

const BUILT_PATHS = new Set(['/overview'])

export function AppRoutes() {
  return (
    <Routes>
      <Route element={<DashboardShell />}>
        <Route path="/" element={<Navigate to="/overview" replace />} />
        <Route path="/overview" element={<Overview />} />
        {NAV_ITEMS.filter((item) => !BUILT_PATHS.has(item.to)).map((item) => (
          <Route
            key={item.key}
            path={item.to}
            element={<Placeholder labelKey={item.labelKey} />}
          />
        ))}
      </Route>
    </Routes>
  )
}

export default function App() {
  return (
    <BrowserRouter>
      <AppRoutes />
    </BrowserRouter>
  )
}
